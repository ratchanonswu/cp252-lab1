# cp252-lab1
## Functional Requirement 
1: ผู้ใช้สามารถสร้างบัญชี ลงทะเบียน และเข้าสู่ระบบด้วยอีเมลหรือเบอร์โทรศัพท์  
2: การค้นหาห้างสรรพสินค้า ผู้ใช้สามารถค้นหาห้างสรรพสินค้าตามชื่อ สถานที่ หรือพื้นที่ใกล้เคียง  
3: ระบบแสดงจำนวนที่จอดรถว่างแบบ real-time ของแต่ละห้างสรรพสินค้า พร้อมแยกตามชั้นและโซน  
4: ผู้ใช้สามารถจองที่จอดรถล่วงหน้าโดยระบุวันที่ เวลา และระยะเวลาที่ต้องการจอด พร้อมรับหมายเลขที่จอดเฉพาะ  
5: ผู้ใช้สามารถยกเลิกการจองที่จอดรถก่อนถึงเวลาที่กำหนด ระบบจะคืนสถานะที่จอดเป็นว่างอัตโนมัติ  
6: ระบบหมดอายุการจอง เมื่อหมดเวลาการจองที่กำหนดไว้ ระบบจะปรับสถานะที่จอดเป็นว่างโดยอัตโนมัติ  
7: การคำนวณค่าธรรมเนียม ระบบคำนวณค่าจอดรถตามระยะเวลาที่จอดจริง โดยมีอัตราค่าบริการตามที่ห้างกำหนด (เช่น ชั่วโมงแรก 20 บาท ชั่วโมงต่อไป 10 บาท)  
8: การนับจำนวนรถในลานจอด ระบบติดตามและแสดงจำนวนรถที่จอดอยู่ทั้งหมดในห้างแต่ละแห่ง แยกตามชั้นและโซน  
9: การจัดการที่จอดรถสำหรับห้างเจ้าของห้างสรรพสินค้าสามารถเพิ่ม ลด หรือแก้ไขจำนวนที่จอดรถ กำหนดอัตราค่าบริการ และจัดการโซนพิเศษ (เช่น ที่จอดคนพิการ)  
10: ประวัติการใช้งานและการชำระเงิน ผู้ใช้สามารถดูประวัติการจอดรถ การจอง และชำระค่าบริการผ่านแอปพลิเคชัน (QR Code, บัตรเครดิต)  
## Non-functional Requirement
1: ระบบต้องมีประสิทธิภาพ ระบบต้องแสดงข้อมูลที่จอดรถว่างแบบ real-time โดยมีความล่าช้าไม่เกิน 2 วินาที และรองรับผู้ใช้พร้อมกันได้อย่างน้อย 10,000 คน  
2: ระบบต้องสามารถใช้งานได้ตลอด 24/7 โดยมี uptime ไม่ต่ำกว่า 99.5% ต่อเดือน  
3: Security ข้อมูลผู้ใช้และการชำระเงินต้องได้รับการเข้ารหัส ป้องกันการเข้าถึงโดยไม่ได้รับอนุญาต และปฏิบัติตามมาตรฐาน PDPA  
4: ระบบต้องสามารถรองรับการเพิ่มห้างสรรพสินค้าและจำนวนที่จอดรถได้โดยไม่กระทบต่อประสิทธิภาพ  
5: แอปพลิเคชันต้องมี UI/UX ที่ใช้งานง่าย เข้าใจง่าย รองรับทั้งภาษาไทยและอังกฤษ และเข้าถึงได้สำหรับผู้พิการ  

TOR Requirement
1. User interface ของเว็ปไซต์ที่ทันสมัยดู minimal เข้าใจง่าย เป็น responsive design
